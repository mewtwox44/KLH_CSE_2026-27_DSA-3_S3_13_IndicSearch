🧠 DSA Algorithms Used

Every stage of the search pipeline uses a specific data structure or algorithm.

01
#️⃣

HashMap

DOCUMENT STORAGE

Stores document IDs and their corresponding document objects for fast lookup.

Lookup O(1) average
02
🔎

Inverted Index

KEYWORD RETRIEVAL

Maps each keyword to the documents where that keyword occurs and stores its frequency.

Search Fast keyword lookup
03
↕️

Merge Sort

RESULT RANKING

Sorts matching documents by their keyword frequency to produce ranked results.

Time O(n log n)
04
🌳

Trie

PREFIX SUGGESTIONS

Stores words character-by-character and supports prefix-based search suggestions.

Prefix Search O(L)
